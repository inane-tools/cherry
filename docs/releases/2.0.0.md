Cherry 2.0 **Furano** moves to Electron and Chromium on Windows and Linux, with Cherry's custom interface intact. This replaces the WebKitGTK renderer that caused animation and rendering issues on Linux.

## Moving from Cherry 1.x

**Keep the old Cherry installed until you have finished migrating.** Close the old app, install 2.0, accept the welcome-screen disclaimer and choose **Migrate from 1.x**. You can import appearance settings, pins, folders, supported preferences, YouTube Music sign-in and Last.fm credentials. Check that your imported data works, then uninstall the old Cherry if you want. Uninstalling it first may remove credentials needed for migration.

Tauri 1.x cannot install this update automatically. On Windows, 2.0 uses **inane → Cherry** in the Start menu so it can coexist with the old installation.

## What's new

- Refreshed navigation, Phosphor icons, context-menu shortcuts and a main menu with Settings, your profile and Quit.
- A floating compact player with track information as the seek bar, plus fullscreen audio/video and controls that slide away during video playback.
- Unified playlist, album, artist and profile headers with banner artwork. Home and Explore gain improved shelves, filters and navigation that restores your scroll position.
- Profile pages with public collections and your private repeat-listening sections. Search filters for songs, artists, albums and playlists, including `@songs`, `@artists`, `@albums` and `@playlists`.
- Pin songs, albums and artists as well as playlists. Pins and their ordering stay separate for each YouTube channel.
- Create playlists with a description and cover image, remove individual playlist entries, and add music to the queue from more places.
- Smooth accent transitions, tinted surfaces and a startup fade that restores your last palette before revealing content.

## Fixes and performance

- Chromium rendering on Linux; no WebKit-specific animation workarounds.
- More reliable account/brand-channel handling, playlist ownership and library refreshes.
- HD video in packaged builds, improved quality switching and recovery from stalled streams. Fixed outgoing playback events seeking into or skipping the next song.
- Large playlists, albums and queues render visible rows instead of mounting every track. Smaller artwork requests, bounded caches and fewer unnecessary playback updates reduce retained work and memory.
- More stable custom scrollbars, artwork recovery and duplicate-song highlighting. Region-blocked songs skip automatically.
- Desktop media controls, Windows Jump Lists and taskbar buttons, Discord Rich Presence and Last.fm integration carry over to Electron.

## Downloads and updates

- **Windows x64:** `Cherry-Setup-2.0.0-x64.exe` (NSIS). The installer is currently unsigned.
- **Linux x86_64:** `Cherry-2.0.0-x86_64.AppImage` or `Cherry-2.0.0-x86_64.flatpak`. macOS remains deferred.
- Windows and AppImage check GitHub for updates. Download and **Install and restart** are explicit actions; normal quitting does not install an update.
- Flatpak is a self-distributed bundle and updates manually; Cherry is not on Flathub.
- Electron 1.7.1 previews receive this release through the old `cherry-electron` update bridge. After installation, future checks use `inane-tools/cherry` directly.

The YAML files and blockmaps are Electron updater assets; `latest.json` keeps legacy Tauri clients on their final compatible version. For a manual installation, download only the package for your platform.
