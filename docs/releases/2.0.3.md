Furano. Playlist library fixes and macOS window polish.

- Empty and video-only YouTube playlists now appear alongside YouTube Music
  playlists in the library and edit menus.
- Account and brand switches isolate in-flight reads and edits, and preserve
  confirmed changes while YouTube's library responses catch up.
- Library pagination loads beyond the previous five-page limit. Failed later
  pages keep the playlists already loaded visible and are not cached as complete.
- Playlist rename requests now include the correct target, and descriptions can
  be cleared.
- Playlist image errors remain visible above dialogs. Upload and cover-attach
  failures are reported separately.
- On macOS, native traffic lights re-align after window layout changes. The
  sidebar and topbar follow the page background and retain scrolling blur.

**Known issue:** YouTube may still reject applying a playlist cover with HTTP
403. That permission denial remains unresolved; this release makes it clearer.
