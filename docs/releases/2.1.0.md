Cherry 2.1.0 **Mombetsu** improves album browsing and network compatibility.

## Albums and artists

- **Popularity** in album track lists: five bars compare each track's YouTube play count with the most-played track in that album. Hover for the reported count. YouTube may round these figures; unavailable counts show a dash. No extra per-track requests are needed.
- **Open album** in album context menus.
- The **Albums** heading on artist pages opens the full discography grid rather than an empty playlist.
- Artist **Top songs** retain song actions, including **Go to album**, instead of being mistaken for mixes because their menus contain a Start mix link.

## Connection handling

- Profile loading, playback setup and artwork requests use Chromium's OS-aware networking, matching the login window. Explicit account cookies and brand-channel selection remain isolated from Chromium's cookie jar.
- Transient connection resets on GET/HEAD requests retry once. Playlist edits and other mutations are not automatically replayed.
- Connection failures show clearer DNS/TLS diagnostics instead of the generic Electron “fetch failed” message. Certificate-authority errors no longer look like an expired login.

## Moving from Cherry 1.x

**Keep the old Cherry installed until you have finished migrating.** Close it, install 2.1.0, accept the welcome-screen disclaimer and choose **Migrate from 1.x**. Check the imported data before optionally uninstalling the old version; removing it first may delete credentials needed for migration.

**Known issue:** YouTube may still reject applying a custom playlist cover with HTTP 403. That permission denial remains unresolved.
