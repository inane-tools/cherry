Furano. Cherry is now available for macOS on Apple Silicon and Intel.

### macOS

- Install using the DMG for your Mac: **arm64** for Apple Silicon or **x64** for
  Intel. Open it and drag Cherry into Applications.
- Native traffic lights stay aligned with the topbar as UI zoom changes.
- The sidebar leaves room for window controls, and shares the topbar background
  in both expanded and compact modes.
- Native application menus and Dock activation; reopening Cherry focuses the
  existing instance. macOS does not create a menu-bar tray.
- Disk images use the same artwork as the Windows installer.

These builds are **ad-hoc signed and not notarized**. macOS may require approval
in System Settings → Privacy & Security after opening a downloaded build.
Updates are manual: quit Cherry and replace the app in Applications. Settings
and local data are stored separately and retained; Keychain access or sign-in
may need to be approved again after replacing an ad-hoc build.

Windows and Linux packages continue to ship alongside the new macOS installers.
