Cherry 2.1.2 **Mombetsu** improves Linux desktop integration and Linux/macOS titlebar layout.

- **Linux window controls** follow the desktop's button placement and icon theme. Show window controls now works immediately, without restarting the app or reloading playback. Rounded window corners are retained.
- **KDE and other Linux media widgets** can set shuffle and repeat. Changes stay synchronized with Cherry's queue and saved preferences.
- **Linux/macOS titlebars** leave room for the full left-side control group, including with multiple buttons, resized sidebars and different UI zoom levels.
- The **top-right menu** stays clickable with the large queue open.
- **Scrolling blur** keeps a subtle tint. With the expanded sidebar it covers only the content column; the sidebar has a subtle divider. Compact sidebars keep the full-width topbar treatment.

Windows keeps its existing window controls, titlebar appearance and media-session behavior. A larger titlebar redesign is deferred to 2.2.
