Cherry 2.0.1 **Furano** fixes library and metadata issues, improves desktop media controls and adds a few useful settings and context-menu actions.

## Changes

- **Go to album** in song context menus. Missing album links are looked up when you use the action; album headers use the album's own artist information.
- **Copy music link** in album context menus.
- A Last.fm scrobbling slider with **1–100%** control in 1% steps, including **25%**. It saves when you release the slider; the default remains 50%.
- The inane.tools Bluesky profile in Settings, with adjusted social-icon sizing and alignment.

## Fixes

- Adding songs to **Liked Songs** uses YouTube's rating endpoint, fixing HTTP 400 errors. Removing liked songs clears the rating, and re-liking a song no longer adds an optimistic duplicate to the displayed list.
- Soundtrack composers without artist links no longer get replaced by the linked album name. Artist, album and year stay separate in mix/video metadata.
- Song credits display commas between contributors, including names separated by line breaks in YouTube's response.
- Audio/video handoffs retain the outgoing media source until the next one starts, improving continuity of the Windows media controls card.
- Flatpak allows Chromium's actual MPRIS service name so Linux desktops can discover playback controls.
- Update release notes render Markdown and HTML as formatted headings, lists, links and code. Links open externally and executable markup is removed.
- Add-to-playlist and Add-to-queue actions use distinct icons.

## Moving from Cherry 1.x

**Keep the old Cherry installed until you have finished migrating.** Close the old app, install 2.0.1, accept the welcome-screen disclaimer and choose **Migrate from 1.x**. Check your imported settings, library organization and sign-in before optionally uninstalling the old version. Uninstalling it first may remove credentials needed for migration.

Cherry 2.0 users can use the built-in updater on Windows and AppImage. Flatpak bundles update manually. macOS remains deferred.
